Obsolete: 더 이상 쓸모없게 된, 구식의

프로그래밍에서는 다음과 같은 상황에 사용됨
- 대체제 등장: 더 성능이 좋거나 구조가 개선된 새로운 함수가 나왔을 때
- 삭제 예정: 향후 업데이트에서 이 기능을 아예 제거할 계획이니 미리 경고
- 사용 권장 안 함: 유지보수나 보안상의 이유로 더 이상 사용하지 않기를 권할 때

왜 바로 삭제하지 않고 `[Obsolete]`를 쓰는가?
- 기존에 이 기능을 사용하던 수많은 프로젝트들이 있을 텐데, 한번에 삭제해버리면 업데이트하자마다 모든 로직이 무너지기 때문
- `[Obsolete]` 경고로 충분한 유예 기간을 준 뒤, 안정화 되었을 때 안전하게 제거하기 위함

직접 게임 엔진이나 시스템을 설계할 때, 기존 코드를 리팩토링한다면 바로 지우지 말고 `[Obsolete]`를 활용해 협업자나 본인에게 "이건 나중에 지울 거야"라는 신호를 주는 습관을 들이면 좋다.

```Csharp
[Obsolete]
public void OldMethod() { ... }
```

기본적인 형태로, 해당 키워드를 추가하면 IDE나 유니티 콘솔에 경고(Warning)가 표시된다.(코드는 정상적으로 빌드)

```Csharp
[Obsolete("이 함수는 오래되었습니다. 대신 NewMethod()를 사용하세요.")]
public void OldMethod() { ... }
```

문자열을 ()안에 추가할 수 있다. 마우스를 올리면 메시지가 출력된다.

```Csharp
[Obsolete("이 함수는 이제 사용할 수 없습니다.", true)]
public void OldMethod() { ... }
```

강제로 컴파일 에러를 일으켜 빌드를 막아버릴 수 있다. (반드시 코드를 수정해야 할 경우 사용)
