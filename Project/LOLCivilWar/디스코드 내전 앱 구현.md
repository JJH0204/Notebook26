# Excalidraw Data

## Text Elements
1. 내전을 진행하는 디스코드 서버에서 관리자가 "/내전준비" 명령어를 입력
2. 디스코드 앱이 내전 준비 상태가 되어 관리자와 참가자들이 데이터를 입력할 수 있는 웹 URL을 지정된 채널에 출력
3. 사용자는 URL로 접속해 자신의 데이터를 입력 후 복사 가능한 코드를 발급 받음
4. 발급된 코드를 디스코드 채널에 "/참가신청 [코드]" 형태로 입력
5. 모든 참가자(10명)이 만들어지면 서버 관리자는 "/밸런스" 입력
6. 디스코드 앱은 모든 참가자 데이터가 입력된 밸런싱 웹 페이지 URL을 채널에 입력
7. 관리자는 해당 웹 페이지에 접속해 밸런싱 결과를 확인
8. 관리자는 "/내전시작 [진행횟수] [규칙]"을 입력
9. 디스코드 앱은 내전 진행을 위한 음성대화 채널 생성(5인 참가 제한), 구성된 팀원들이 입장할 수 있도록 안내
10. 정해진 규칙에 따라 내전을 진행. (진행 사항을 관리자가 "/명령어"를 통해 디스코드 앱에서 동적으로 관리할 수 있도록 입력)
11. 내전이 종료되면 (마지막 회차 대전 결과를 관리자가 "/명령어"를 통해 입력하면 내전 종료) 동적으로 생성된 음성채널을 삭제, 해당 채널을 이용하던 사용자를 모두 대기실로 이동, 내전 결과를 디스코드 채널에 출 ^UJti711c
