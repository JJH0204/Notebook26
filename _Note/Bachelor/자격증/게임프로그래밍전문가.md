# 게임프로그래밍전문가

> 국가기술자격. 게임 개발 배경을 살릴 수 있는 전문 자격증.
> 학점은행제 컴퓨터공학 전공 인정 여부 및 학점 수는 **공식 확인 필요**.

---

## 기본 정보

| 항목 | 내용 |
|------|------|
| 자격 종류 | 국가기술자격 (전문가) |
| 주관 기관 | 한국콘텐츠진흥원(KOCCA) — [kgq.or.kr](https://www.kgq.or.kr) |
| 응시 자격 | **제한 없음** |
| 수수료 | 필기 18,800원 / 실기 23,700원 |
| 시험 횟수 | 연 2~3회 |

---

## 시험 과목

### 필기 (4과목, 객관식)

| 과목 | 주요 내용 |
|------|-----------|
| 게임제작 개론 | 게임 개발 파이프라인, 엔진 구조, 프로젝트 관리 |
| 프로그래밍 일반 | 자료구조, 알고리즘, OOP, 메모리 관리 |
| 게임 알고리즘 | 충돌 검출, 물리 시뮬레이션, AI(행동 트리, FSM), 경로 탐색 |
| 게임 프로그램 제작 | 렌더링, 게임 루프, 입력 처리, 네트워크 게임 기초 |

- 합격 기준: 전체 평균 60점 이상 (과목별 40점 이상)

### 실기 (게임프로그래밍 실무)

- 실제 코드 작성 또는 문제 풀이 형태
- 합격 기준: 60점 이상

---

## 합격률

| 구분 | 합격률 |
|------|--------|
| 필기 | 약 30~60% (연도별 편차 큼) |
| 실기 | 약 40~65% |

> 응시 인원 자체가 적어 연도별 변동이 크다. 게임 개발 실무 경험자라면 실기 준비 부담이 낮음.

---

## 학점은행제 인정

| 항목 | 내용 |
|------|------|
| 인정 학점 | ⚠️ **공식 확인 필요** (기사급 준용 시 약 18~20학점 추정) |
| 학점 구분 | ⚠️ **컴퓨터공학 전공 인정 여부 공식 확인 필요** |
| 슬롯 활용 | 정보처리산업기사와 다른 직무 → 슬롯 중복 없음 |

> - [ ] [학점은행 전공별 자격연계](https://www.cb.or.kr/creditbank/eduIntro/nEduIntro2_4_3.do)에서 컴퓨터공학 선택 후 게임프로그래밍전문가 검색하여 인정 학점·전공 여부 확인
> - [ ] 해당 자격이 목록에 없을 경우 학점은행 콜센터(1600-0510) 문의

---

## 준비 참고

- Unity/Unreal 프로젝트 경험이 있으면 필기 게임 알고리즘·제작 과목 접근 쉬움
- 프로그래밍 일반 과목은 C++/C# 기반 자료구조·알고리즘 위주로 출제
- 기출문제 수가 적어 KGQ 공식 사이트 기출 + 나무위키 자료 참고 권장

---

## 활용도

- 게임 프로그래머 직군 포트폴리오 강화
- 이력서·지원서에서 게임 전문성 증명 수단
- 게임 관련 공공 지원사업 참여 자격 요건에 활용 가능성 있음
