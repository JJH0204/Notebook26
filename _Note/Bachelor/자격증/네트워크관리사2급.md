# 네트워크관리사 2급

> 국가공인 민간자격. 응시 제한 없고 합격률도 적당한 편.
> 학점은행제 컴퓨터공학 전공 **14학점** 인정 확인됨.

---

## 기본 정보

| 항목 | 내용 |
|------|------|
| 자격 종류 | 국가공인 민간자격 |
| 주관 기관 | 한국정보통신자격협회(ICQA) — [icqa.or.kr](https://www.icqa.or.kr) |
| 응시 자격 | **제한 없음** |
| 시험 횟수 | 연 4회 이상 (분기별 시행) |

---

## 시험 과목

### 필기 (4과목, 객관식)

| 과목 | 주요 내용 |
|------|-----------|
| 네트워크 일반 | OSI 7계층, 이더넷, 무선 LAN |
| TCP/IP | IP 주소, 서브넷, 라우팅 프로토콜 |
| NOS (네트워크 운영체제) | Windows Server, Linux 서버 기본 |
| 네트워크 운용기기 | 라우터, 스위치, 허브 구성 |

- 합격 기준: 전체 평균 60점 이상

### 실기

| 영역 | 내용 |
|------|------|
| LAN 전송매체 | 케이블 크림핑 실습 |
| 네트워크 설계/구축 | IP 설계, 토폴로지 구성 |
| TCP/IP | 실제 설정 |
| NOS | 서버 기본 설정 |
| 네트워크 운용기기 | 라우터/스위치 CLI 설정 |

- 합격 기준: 60점 이상

---

## 합격률

| 구분 | 합격률 |
|------|--------|
| 필기 | 약 50~60% |
| 실기 | 약 40~50% |

> 전반적으로 취득 난이도 중간 수준.

---

## 학점은행제 인정

| 항목 | 내용 |
|------|------|
| 인정 학점 | **14학점** ✅ (확인됨) |
| 학점 구분 | **전공** (컴퓨터공학) ✅ |
| 슬롯 활용 | 정보처리산업기사와 다른 직무 → 슬롯 중복 없음 |

---

## 활용도

- 네트워크 인프라 직군 (IDC, 네트워크 엔지니어) 취업 시 기본 자격
- 1급 취득 발판으로 활용 가능
- 게임 서버 인프라 이해에도 도움
