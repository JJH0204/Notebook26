# 리눅스마스터 1급

> 국가공인 민간자격. 리눅스 서버 전문가 자격.
> 합격률이 한 자릿수로 **취득 난이도가 높음**. 학점은행제 최대 18학점 인정 가능.

---

## 기본 정보

| 항목 | 내용 |
|------|------|
| 자격 종류 | 국가공인 민간자격 |
| 주관 기관 | 한국정보통신진흥협회(KAIT) — [ihd.or.kr](https://www.ihd.or.kr) |
| 응시 자격 | **1차: 제한 없음** / 2차: 해당 종목 1차 합격 후 2년 이내 |
| 시험 구조 | 1차(필기) → 2차(실기) 2단계 |
| 시험 횟수 | 연 2회 (상·하반기) |

---

## 시험 과목

### 1차 필기 (객관식)

| 과목 | 주요 내용 |
|------|-----------|
| 리눅스 실무의 이해 | 리눅스 역사, 배포판, 파일 시스템, 기본 명령어 |
| 리눅스 시스템 관리 | 사용자 관리, 프로세스, 패키지, 디스크 관리, 쉘 스크립트 |
| 네트워크 및 서비스 활용 | DNS, DHCP, 웹서버(Apache), FTP, 방화벽, 보안 설정 |

- 합격 기준: 과목당 40점 이상, 전체 평균 60점 이상

### 2차 실기 (실무형)

- 리눅스 시스템 실무: 서버 구성·운영 실습
- 합격 기준: 60점 이상

---

## 합격률

| 구분 | 합격률 |
|------|--------|
| 1차 필기 | 약 20~35% |
| 2차 실기 | 약 8~15% ⚠️ 매우 낮음 |

> 2024년 최종 합격률 **8.97%**. 실제 리눅스 운용 경험 없이는 실기 통과 어려움.

---

## 학점은행제 인정

| 항목 | 내용 |
|------|------|
| 인정 학점 | 최대 **18학점** (⚠️ 취득 시기·고시에 따라 변동 가능) |
| 학점 구분 | 전공 인정 여부 ⚠️ 공식 확인 필요 |
| 슬롯 활용 | 정보처리산업기사와 다른 직무 → 슬롯 중복 없음 |

> - [ ] [학점은행 전공별 자격연계](https://www.cb.or.kr/creditbank/eduIntro/nEduIntro2_4_3.do)에서 인정 학점 및 전공 여부 확인

## 준비 참고

- 실제 리눅스(Ubuntu/CentOS) 환경 구축 후 서버 직접 운영해보는 것 권장
- VirtualBox나 WSL2로 실습 환경 꾸리기
- 서버 배포 경험(게임 서버, 웹서버 등)이 있으면 실기 준비 유리

## 활용도

- 서버·인프라 엔지니어, DevOps, 백엔드(서버 운영) 직군 우대
- 게임 서버 운영 실무에 직접 연결되는 지식
