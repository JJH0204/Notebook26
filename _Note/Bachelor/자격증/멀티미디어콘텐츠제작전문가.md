# 멀티미디어콘텐츠제작전문가

> 국가기술자격. 응시 제한 없고 합격률이 높아 취득 난이도가 낮은 편.
> 학점은행제 **18학점** 인정 확인됨. 컴퓨터공학 전공 인정 여부는 공식 확인 필요.

---

## 기본 정보

| 항목 | 내용 |
|------|------|
| 자격 종류 | 국가기술자격 (전문가) |
| 주관 기관 | 한국산업인력공단 — [q-net.or.kr](https://www.q-net.or.kr) |
| 응시 자격 | **제한 없음** |
| 시험 횟수 | 연 3회 |

---

## 시험 과목

### 필기 (4과목, 객관식)

| 과목 | 주요 내용 |
|------|-----------|
| 멀티미디어개론 | 멀티미디어 개념, 데이터 압축, 파일 포맷, 스트리밍 |
| 멀티미디어 기획 및 디자인 | UI/UX 기획, 색채·레이아웃 원리, 스토리보드 |
| 멀티미디어 저작 | 저작 도구 활용(HTML, CSS, 애니메이션 등) |
| 멀티미디어 제작 기술 | 영상·음향 편집, 3D 기초, 웹 퍼블리싱 |

- 합격 기준: 과목당 40점 이상, 전체 평균 60점 이상

### 실기 (작업형, 4시간)

- 멀티미디어 콘텐츠 제작 실무
- 포토샵·일러스트레이터·HTML/CSS 활용 등
- 합격 기준: 60점 이상

---

## 합격률

| 구분 | 합격률 |
|------|--------|
| 필기 | 약 40~60% |
| 실기 | 약 63~80% ✅ 비교적 높음 |

> 전체적으로 취득 난이도가 낮은 편. 디자인·웹 기본기가 있으면 더욱 유리.

---

## 학점은행제 인정

| 항목 | 내용 |
|------|------|
| 인정 학점 | **18학점** ✅ (확인됨) |
| 학점 구분 | ⚠️ **컴퓨터공학 전공 인정 여부 공식 확인 필요** |
| 슬롯 활용 | 정보처리산업기사와 다른 직무 → 슬롯 중복 없음 |

> 멀티미디어 관련 전공(시각·영상 등)에서는 전공 인정되는 경우 있으나,
> 컴퓨터공학 전공 인정 여부는 별도 확인이 반드시 필요.

> - [ ] [학점은행 전공별 자격연계](https://www.cb.or.kr/creditbank/eduIntro/nEduIntro2_4_3.do)에서 컴퓨터공학 선택 후 멀티미디어콘텐츠제작전문가 검색하여 전공 인정 여부 확인

---

## 준비 참고

- 포토샵·일러스트레이터 기초 실습 환경 필요 (실기)
- HTML/CSS 기본 작성 가능하면 저작 과목 유리
- 기출문제 CBT 사이트([comcbt.com](https://www.comcbt.com/xe/d4))에서 필기 대비 가능

## 활용도

- 영상·UI 콘텐츠 직군, 콘텐츠 기획·제작사 취업 시 유리
- 게임 개발팀 내 UI/UX, 애니메이션 담당자로서의 역량 증명
- 18학점 인정이 확인되어 학점은행제 활용 가치 높음
