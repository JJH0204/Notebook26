# 빅데이터분석기사

> 2020년 신설된 국가기술자격. 데이터 분석·ML 직군 진출 시 유리.
> 학점은행제 **20학점** 인정 확인됨. 응시 장벽 낮고 합격률도 비교적 높은 편.

---

## 기본 정보

| 항목 | 내용 |
|------|------|
| 자격 종류 | 국가기술자격 (기사) |
| 주관 기관 | 한국산업인력공단 — [q-net.or.kr](https://www.q-net.or.kr) |
| 응시 자격 | ① 4년제 대학 졸업(예정) — **전공 무관** <br>② 기사 등급 이상 자격증 보유 (종목 무관) <br>③ 전문대 졸업 + 실무경력 1년 <br>④ 산업기사 취득 + 실무경력 2년 <br>⑤ 실무경력 4년 이상 |
| 시험 횟수 | 연 2~3회 |

> 정보처리산업기사 보유 시 ②번 경로로 **즉시 응시 가능**.

---

## 시험 과목

### 필기 (4과목, 80문항, 120분)

| 과목 | 주요 내용 |
|------|-----------|
| 빅데이터 분석기획 | 데이터 수집·저장·처리 아키텍처, 분석 프로젝트 관리 |
| 빅데이터 탐색 | 데이터 전처리, EDA, 통계 기초 |
| 빅데이터 모델링 | 머신러닝 알고리즘, 모델 선택, 하이퍼파라미터 |
| 빅데이터 결과 해석 | 모델 평가, 시각화, 비즈니스 인사이트 도출 |

- 합격 기준: 과목당 40점 이상, 전체 평균 60점 이상

### 실기 (통합형, 180분)

- 필답형: 빅데이터 분석 개념 서술
- 작업형: Python/R을 활용한 데이터 분석 실습 (파일 제출)
- 합격 기준: 60점 이상
