# 컴퓨터 공학사 취득용 자격증

> 학점은행제를 통해 컴퓨터공학 학사(140학점)를 취득하기 위한 자격증 전략 정리.
> 자격증 학점인정 기준은 매년 고시되므로, 최신 기준은 [학점은행 공식 사이트](https://www.cb.or.kr/)에서 확인할 것.

---

## 학점인정 기본 규칙

- 학사 과정 기준 **최대 3개**까지 자격증 학점인정 가능
- 구성: **전공 자격증 3개** 또는 **전공 자격증 2개 + 일반 자격증 1개**
- **동일 직무번호** 자격증은 여러 개 취득해도 **1개만** 인정
  - 예) 정보처리산업기사 ↔ 정보처리기사 → 동일 직무 → 중복 인정 불가
- 전공 자격증: 전공 학점으로 인정 / 일반 자격증: 일반선택 학점으로 인정

---

## 취득 현황 및 전략

| 상태 | 자격증 | 구분 | 인정 학점 | 상세 파일 |
|------|--------|------|-----------|-----------|
| ✅ 취득 완료 | **[[정보처리산업기사]]** | 전공 | 16학점 | → [[정보처리산업기사]] |
| 🎯 취득 목표 | (아래 후보 중 선택) | 전공 | — | 슬롯 2/3 |
| 🎯 취득 목표 | (아래 후보 중 선택) | 전공 또는 일반 | — | 슬롯 3/3 |

> 정보처리기사는 정보처리산업기사와 동일 직무번호이므로 **학점은행제 자격증 슬롯 인정에서는 제외**됨.
> 단, 실무·취업 목적으로 별도 취득 가치는 충분함.

## 🎮 게임·콘텐츠 관련 자격증 (관심 종목)

> 게임 개발 배경을 살릴 수 있는 자격증. 학점은행제 컴퓨터공학 전공 인정 여부는 공식 사이트에서 반드시 확인 필요.

### 게임프로그래밍전문가

| 항목 | 내용 |
|------|------|
| 주관 기관 | 한국콘텐츠진흥원 (KOCCA) — [kgq.or.kr](https://www.kgq.or.kr) |
| 응시 자격 | **제한 없음** |
| 필기 과목 | 게임제작개론, 프로그래밍일반, 게임알고리즘, 게임프로그램제작 (4과목) |
| 실기 과목 | 게임프로그래밍 실무 |
| 합격 기준 | 필기: 전체 60% 이상 (과목별 40% 이상) / 실기: 60점 이상 |
| 수수료 | 필기 18,800원 / 실기 23,700원 |
| 인정 학점 | **공식 확인 필요** (기사급 준용 시 약 18~20학점 추정) |
| 전공 인정 여부 | **공식 확인 필요** — 컴퓨터공학 또는 게임공학 전공 연계 가능성 있음 |
| 비고 | 게임 개발 실무 경험 있으면 실기 난이도 낮음. 필기 합격률 변동 폭 큼 |

## 추천 취득 순서 (전략안)

```
✅ 정보처리산업기사 (취득 완료, 16학점 전공)
    ↓
🎯 [고학점 전공 슬롯 2] 아래 후보 중 1개 선택
    - 게임프로그래밍전문가  ← 게임 개발 배경 활용, 전공 인정 여부 확인 필요
    - 멀티미디어콘텐츠제작전문가  ← 약 18학점, 응시 장벽 낮음
    - 정보보안기사  ← 약 20학점이나 응시자격 요건 확인 필요
    - 빅데이터분석기사  ← 데이터 직군 지향 시
    ↓
🎯 [전공 슬롯 3 또는 일반 슬롯] 아래 후보 중 1개 선택
    - 네트워크관리사 2급  ← 전공 약 14학점
    - 리눅스마스터 1급  ← 서버/인프라 직군 유리
    - 컴퓨터활용능력 1급  ← 일반선택 약 14학점
```

> 총 자격증 인정 학점 예상: 약 46~54학점 (전공 학점 목표 60학점 중 상당 부분 충당 가능)
