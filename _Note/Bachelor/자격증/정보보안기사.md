# 정보보안기사

> 보안 분야 최고 권위의 국가기술자격. 고학점 + 실무 가치 모두 높음.
> 학점은행제 슬롯 2번 후보 중 **최우선 고려 대상**.

---

## 기본 정보

| 항목 | 내용 |
|------|------|
| 자격 종류 | 국가기술자격 (기사) |
| 주관 기관 | 한국인터넷진흥원(KISA) / 시험 시행: 한국방송통신전파진흥원(KCA) — [cq.or.kr](https://www.cq.or.kr) |
| 응시 자격 | ① 관련학과 4년제 대학 졸업 — **전공 무관 (모든 학과 해당)** <br>② 전문대 졸업 + 실무경력 1년 <br>③ 비관련학과 대학 졸업 + 실무경력 2년 <br>④ 실무경력 4년 이상 <br>⑤ 학점은행제 106학점 이상 취득 시 가능 |
| 시험 횟수 | 연 2회 |

---

## 시험 과목

### 필기 (5과목, 객관식)

| 과목 | 주요 내용 |
|------|-----------|
| 시스템 보안 | OS 보안, 악성코드, 취약점 분석 |
| 네트워크 보안 | TCP/IP, 방화벽, IDS/IPS, 암호화 |
| 애플리케이션 보안 | 웹 보안, 소프트웨어 보안, DB 보안 |
| 정보보안 일반 | 암호학, 접근제어, 인증 |
| 정보보안 관리 및 법규 | ISMS, 개인정보보호법, 전자서명법 |

- 합격 기준: 과목당 40점 이상, 전체 평균 60점 이상

### 실기 (필답형, 180분)

- 5과목 내용을 통합하여 단답형·서술형 출제
- 합격 기준: 60점 이상

---

## 합격률

| 구분 | 합격률 |
|------|--------|
| 필기 | 약 30~40% |
| 실기 | 약 10~20% ⚠️ 높은 난이도 |

> 실기 평균 합격률이 10% 초반대. 단순 암기보다 심층적 이해 필요.

---

## 학점은행제 인정

| 항목 | 내용 |
|------|------|
| 인정 학점 | 약 **20학점** (기사급, ⚠️ 공식 확인 필요) |
| 학점 구분 | **전공** (컴퓨터공학 전공 인정 가능성 높음, ⚠️ 공식 확인 필요) |
| 슬롯 활용 | 정보처리산업기사와 **다른 직무번호** → 슬롯 중복 없이 인정 가능 |

> - [ ] [학점은행 전공별 자격연계](https://www.cb.or.kr/creditbank/eduIntro/nEduIntro2_4_3.do)에서 컴퓨터공학 → 정보보안기사 조회하여 인정 학점 확인

---

## 응시자격 충족 방법

- 학점은행제로 106학점(이수) 달성 시 응시 가능
  - 현재 정보처리산업기사(16학점) + 추가 수업 이수로 충족 가능
- 응시자격 자가진단: [Q-net 응시자격 조회](https://www.q-net.or.kr/man001.do?id=man00104)

---

## 활용도

- 정보보안 직군 채용 시 거의 필수 자격
- 공공기관·금융권 IT 보안 포지션 우대
- 산업기사 대비 처우·직급 차이 발생
