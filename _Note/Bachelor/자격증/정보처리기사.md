# 정보처리기사

> IT 분야 대표 국가기술자격. 취업·대외 인지도 높음.
> 학점은행제 슬롯상 **정보처리산업기사와 동일 직무번호**이므로 추가 학점 인정 불가. 실무 목적으로만 고려.

---

## 기본 정보

| 항목 | 내용 |
|------|------|
| 자격 종류 | 국가기술자격 (기사) |
| 주관 기관 | 한국산업인력공단 — [q-net.or.kr](https://www.q-net.or.kr) |
| 응시 자격 | ① 관련학과 4년제 대학 졸업(예정) — **전공 무관** <br>② 전문대 졸업 + 실무경력 1년 <br>③ 비관련학과 대학 졸업 + 실무경력 2년 <br>④ 학점은행제로 106학점(관련학과 기준 4년제 동등) 이상 |
| 시험 횟수 | 연 3회 (1·2·3회차) |

## 시험 과목

### 필기 (5과목, 객관식)

| 과목 | 주요 내용 |
|------|-----------|
| 소프트웨어 설계 | 요구사항 분석, UML, 디자인 패턴 |
| 소프트웨어 개발 | 알고리즘, 테스트, 버전관리 |
| 데이터베이스 구축 | 관계형 DB, SQL, 정규화, 트랜잭션 |
| 프로그래밍 언어 활용 | C, Java, Python 기초 |
| 정보시스템 구축관리 | 보안, 네트워크, SW 개발 방법론 |

- 합격 기준: 과목당 40점 이상, 전체 평균 60점 이상

### 실기 (서술형 필답)

- 소프트웨어 개발 관련 전 영역 통합 출제
- 합격 기준: 60점 이상

---

## 합격률

| 구분 | 합격률 |
|------|--------|
| 필기 | 약 40~50% |
| 실기 | 약 10~20% ⚠️ 난이도 높음 |

> 2020년 개정 이후 실기 난이도가 대폭 상승. 단순 암기보다 이해·적용 능력 요구.

---

## 학점은행제 인정

| 항목 | 내용 |
|------|------|
| 인정 학점 | 약 **20학점** (기사급) |
| 학점 구분 | **전공** (컴퓨터공학) |
| ⚠️ 슬롯 주의 | 정보처리산업기사와 **동일 직무번호** → 이미 산업기사로 학점인정 시 기사는 학점은행제 슬롯 **추가 불가** |

> 학점은행제 목적이 아닌 **취업·역량 강화** 목적으로 취득 가치 충분.

## 활용도

- IT 기업 채용 공고에서 우대 또는 필수 자격으로 가장 많이 요구
- 공공기관·공무원 IT직군 가산점 적용
- 정보보안기사 등 상위 자격 응시 경력 조건 충족에 활용 가능
