# 정보처리산업기사 ✅ 취득 완료

> 학점은행제 컴퓨터공학사 자격증 슬롯 1번 사용 완료.

---

## 기본 정보

| 항목 | 내용 |
|------|------|
| 자격 종류 | 국가기술자격 (산업기사) |
| 주관 기관 | 한국산업인력공단 — [q-net.or.kr](https://www.q-net.or.kr) |
| 응시 자격 | 관련학과 전문대 졸업 / 실무경력 2년 이상 / 기능사 취득 후 경력 1년 등 |
| 시험 횟수 | 연 3회 (1·2·3회차) |

---

## 시험 과목

### 필기

| 과목 | 내용 |
|------|------|
| 데이터베이스 | DB 설계, SQL, 정규화 |
| 전자계산기 구조 | CPU, 메모리, 입출력 |
| 시스템 분석 설계 | 개발방법론, UML |
| 운영체제 | 프로세스, 스케줄링, 메모리 관리 |
| 정보통신 개론 | 네트워크, 프로토콜 기초 |

- 합격 기준: 과목당 40점 이상, 전체 평균 60점 이상

### 실기

- 정보처리실무 (필답형)
- 합격 기준: 60점 이상

| 항목 | 내용 |
|------|------|

## 주의사항

> **정보처리기사와 동일 직무번호**이므로, 정보처리기사를 추가 취득해도 학점은행제 자격증 슬롯에서는 중복 인정 불가.
> 단, 정보처리기사는 실무·취업 목적으로 별도 가치가 있으므로 취득 자체는 권장됨.
