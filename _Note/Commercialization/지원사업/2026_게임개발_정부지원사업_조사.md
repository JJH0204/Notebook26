# 2026년 게임 개발 정부 지원사업 조사 보고서

> 기준일: 2026년 4월 11일  
> 대상: 10인 규모 PC/콘솔 게임 개발팀  
> 목적: 도전 가능한 정부 지원사업 식별 및 우선순위 정리

---

## 요약

2026년 현재 도전 가능한 게임 개발 관련 정부 지원사업은 크게 **콘텐츠 제작지원**, **글로벌 마케팅 지원**, **창업 성장지원** 세 트랙으로 나뉜다. 10인 중규모 팀에 가장 직결되는 사업은 한국콘텐츠진흥원(KOCCA) AI 게임 트랙과 SBA 게임마켓 서울관으로, 특히 SBA 게임마켓은 **4월 20일이 마감**으로 즉시 행동이 필요하다.

## 1. 🔥 긴급 — 신청 마감 임박

### SBA 서울경제진흥원 | 2026 게임마켓 서울관 참가기업 모집
| 항목 | 내용 |
|---|---|
| **신청 마감** | **2026년 4월 20일(월) 15:00** |
| **지원 대상** | 서울 소재 게임 개발사 (규모 제한 없음) |
| **지원 게임쇼** | 차이나조이(7월, 상하이), BIC(8월, 부산), 지스타(11월, 부산) |
| **선발 규모** | 차이나조이 9개사, BIC 6개사, 지스타 9개사 (총 24개사 내외) |
| **지원 내용** | ① 서울관 공동부스 임차·구축 전액 지원 ② 홍보물 제작 ③ 통역·운영 인력 ④ 글로벌 퍼블리셔/바이어 사전 매칭 ⑤ B2B 비즈니스 상담 공간 ⑥ 현장 반응 데이터·피드백 리포트 |
| **신청 방법** | SBA 누리집(www.sba.seoul.kr) 공지사항 |
| **주요 조건** | 서울 소재 사업자등록 필요 |

**→ 결론**: PC/콘솔 팀으로서 글로벌 퍼블리셔 미팅이 가능한 최고의 기회. BIC는 인디게임 특화 행사이므로 가장 적합. 지스타도 병행 신청 추천.

## 2. 한국콘텐츠진흥원 (KOCCA) | 게임콘텐츠 제작지원 사업

2026년 총 236억원 투입, 82개 내외 과제 선정.  
사업 설명회는 2월 24일 광화문 CKL기업지원센터에서 이미 진행되었으며, **일반형 신청은 3월 마감**으로 당해 신청 불가. 단, 아래 AI 게임 트랙은 별도 일정 운영.

### 📌 2026년 AI 게임 콘텐츠 제작지원 (신규 신설)
| 항목 | 내용 |
|---|---|
| **지원 금액** | 과제당 최대 **3억원** (국고 90% + 자부담 10% 이상) |
| **선발 규모** | 9개 내외 |
| **사업 기간** | 2026년 4~11월 (8개월) |
| **플랫폼 제한** | 없음 (PC·콘솔·모바일 모두 가능) |
| **선발 방식** | 서면평가 → 발표평가 |
| **지원 분야** | AI 기술을 활용한 게임 콘텐츠 제작 |
| **공고 확인** | www.kocca.kr → 지원공고 |

**→ 결론**: AI 요소(AI NPC, 절차적 생성, AI 아트 등)를 게임에 접목할 수 있다면 최우선 검토. 최대 3억원 + 8개월 지원으로 개발비 충당에 실질적 도움.

### 기타 연간 반복 트랙 (2027년 대비)
- **일반형**: PC·콘솔·모바일·아케이드·보드게임 (과제당 1~2억원대 예상, 매년 1~3월 공모)
- **기능성게임 (지정형)**: 공공 목적 게임 개발
- **인디게임**: 소규모 팀 특화, 별도 공고 확인 필요

## 3. 경기콘텐츠진흥원 | 경기글로벌게임센터 입주 모집

| 항목 | 내용 |
|---|---|
| **모집 대상** | 경기도 소재 또는 이전 예정 게임 기업 |
| **입주 조건** | 기획/개발·MVP 보유기업, 상품/상용화 단계 |
| **지원 내용** | 사무공간 + 경기글로벌게임센터 연계 프로그램 |
| **2026 상반기 일정** | 1월 심사 진행 (하반기 모집 공고 별도 확인 필요) |
| **공고 확인** | www.gcon.or.kr |

**→ 결론**: 팀 사무공간이 필요하거나 경기도 이전이 가능하다면 하반기 모집 공고 주시. 입주 자체가 후속 지원사업 연계로 이어짐.

## 4. 창업진흥원 | 창업도약패키지 (일반형)

|---|---|
| **지원 자격** | 창업 후 **3년 초과 7년 이내** 기업 |
| **지원 금액** | 평균 1.2억원, 최대 **2억원** |

| **게임 분야 주관** | 광주정보문화산업진흥원 (게임·콘텐츠 특화) |
| **패스트트랙** | 초기창업패키지 수료 기업 우대 |
| **신청 포털** | www.k-startup.go.kr |

**→ 결론**: 창업 3~7년차 팀에 해당한다면 일반 사업화 자금으로 활용 가능. 게임 특화 주관기관 선택 시 유리.
