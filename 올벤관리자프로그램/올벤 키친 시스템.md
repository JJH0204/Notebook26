# 🌐 올벤 키친 시스템: 원격 연결 가이드 (Tailscale)

이 가이드는 서로 다른 장소에 있는 **윈도우 관리자 PC**와 **안드로이드 태블릿**을 마치 한 장소에 있는 것처럼 연결해 주는 **Tailscale(테일스케일)** 설정 방법을 설명합니다.

---

## 1. Tailscale이란 무엇인가요? 🏠
일반적으로 주방의 태블릿과 사무실의 PC는 서로 다른 인터넷(와이파이)을 사용하기 때문에 직접 대화할 수 없습니다. 

**Tailscale**은 이 기기들을 연결해 주는 **'전용 가상 복도'**를 만들어 줍니다. 이 복도 안에 들어온 기기들은 세상 어디에 있든 옆방에 있는 것처럼 서로 안전하게 데이터를 주고받을 수 있습니다.

---

## 2. PC 설정 방법 (서버용) 💻

1. **회원가입**: [Tailscale 공식 홈페이지](https://tailscale.com/)에 접속하여 구글 계정 등으로 가입합니다.
2. **프로그램 설치**: 'Download Tailscale for Windows'를 클릭해 설치 파일을 받고 실행합니다.
3. **로그인**: 설치 완료 후 우측 하단 작업 표시줄(시계 옆)의 'T' 모양 아이콘을 클릭해 로그인합니다.
4. **고유 주소(IP) 확인**: 
   * 로그인 후 아이콘을 다시 클릭하면 상단에 `100.xxx.xxx.xxx` 형태의 숫자가 보입니다. 
   * 이 숫자가 이 PC의 **고유 주소(Tailscale IP)**입니다. 태블릿 앱 설정 시 필요하니 꼭 메모해 두세요.

---

## 3. 안드로이드 태블릿 설정 방법 (조리용) 📱

1. **앱 설치**: 구글 플레이 스토어에서 **'Tailscale'**을 검색하여 설치합니다.
2. **로그인**: PC에서 가입했던 것과 **동일한 계정**으로 로그인합니다.
3. **연결(Connect)**: 화면 중앙의 스위치를 눌러 'Connected' 상태로 만듭니다.
   * 처음 연결 시 나타나는 'VPN 연결 요청' 팝업에서 **[확인]**을 눌러야 정상 작동합니다.
4. **확인**: 화면에 내 PC의 이름과 IP 주소가 목록에 보인다면 연결 준비가 끝난 것입니다.



---

## 4. 주방 앱과 최종 연결하기 🔗

1. 태블릿에서 **'올벤 키친 시스템'** 앱을 실행합니다.
2. 좌측 하단의 **[서버 설정]** 버튼을 누릅니다.
3. **서버 IP (Tailscale)** 칸에 아까 PC에서 메모했던 `100.xxx.xxx.xxx` 주소를 정확히 입력합니다.
4. **[연결 테스트]**를 눌러 "연결 성공!" 메시지가 뜨는지 확인한 후 **[데이터 동기화]**를 진행합니다.

---

## 5. 자주 묻는 질문 (FAQ) ❓

* **Q: 집에서도 매장의 주문 현황을 볼 수 있나요?**
  * **A:** 네! 집 PC나 개인 스마트폰에 Tailscale을 깔고 같은 계정으로 로그인만 하면 전 세계 어디서든 연결됩니다.
* **Q: 매번 켜야 하나요?**
  * **A:** 기기를 켜면 자동으로 실행되도록 설정되어 있어, 처음 한 번만 로그인해두면 신경 쓰지 않아도 됩니다.
* **Q: 연결이 안 돼요!**
  * **A:** PC의 Tailscale 아이콘을 클릭했을 때 'Connected' 상태인지, 그리고 윈도우 방화벽에서 프로그램 허용이 되어 있는지 확인해 주세요.

---

> **주의**: 원활한 주문 전송을 위해 관리자 PC의 전원 설정에서 '절전 모드'를 해제하는 것을 권장합니다.
